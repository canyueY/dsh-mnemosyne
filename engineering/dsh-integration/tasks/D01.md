# D01｜稳定自安装

## 目标
新增 `scripts/install-dsh.mjs`（+ `scripts/install-dsh.ps1` 包装），让 DSH 或用户一条命令完成稳定安装。

## 步骤
1. profile 识别：显式参数 → `DSH_PROFILE` → 运行中 DSH 进程命令行里的 `profiles/<name>` → 最近使用 → `web`。
2. 源选择：`--tag <ver>` 用 `github:canyueY/dsh-mnemosyne#<ver>`；`--local` 用 `file:<仓库绝对路径>`；默认本地（开发）。
3. 改动前备份 `package.json`、`cordis.patch.yml`、`pnpm-lock.yaml`（存在才备份），保留最近 N 份。
4. 幂等：已装同版本且 bundle 在位则跳过；版本不同先记录旧版本。
5. 执行 `dsh plugin --profile <profile> add <source>`（Windows 用 `cmd.exe /d /s /c` 运行 `dsh.cmd`；优先 `DSH_CLI`）。
6. 装后自检：`dsh.profile.bundles` 含 `dsh-mnemosyne`；`npm run check`；`node --test src/test/host-compat-021.mjs`。
7. 输出回滚命令与备份路径；失败返回 `{ok:false, code, error, hint}`。

## 完成标准
- 干净临时 `DSH_HOME` 安装成功；二次运行幂等。
- 已有其他 bundle/MCP/preset 的 profile 不被覆盖。
- 装错 profile / 缺 dsh CLI 时报错可诊断。
- DA02、DA03、DA04 通过。
