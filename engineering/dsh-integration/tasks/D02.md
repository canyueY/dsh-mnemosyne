# D02｜稳定迁移与回滚

## 目标
新增 `scripts/migrate-dsh.mjs`（+ `scripts/migrate-dsh.ps1`），把旧 profile/旧 bundle 平滑迁移到 `dsh-mnemosyne`，并可回滚。

## 步骤
1. 识别旧 bundle：profile `dependencies` 或 `dsh.profile.bundles` 中存在 `dsh-cognitive-memory`。
2. 备份 `package.json`、`cordis.patch.yml`、`pnpm-lock.yaml`；迁移前后记录版本与数据目录快照。
3. 替换 dependencies/bundles 中的 `dsh-cognitive-memory` → `dsh-mnemosyne`；其他条目逐字节保留。
4. `cordis.patch.yml` 只增删本包拥有行（id=`dsh-mnemosyne` 或旧 `dsh-cognitive-memory`）。
5. 数据目录：调用 `mnemosyne memory-bank migrate-legacy`（只迁移旧 `DSH\cognitive-memory`），不复制 `memory.db`。
6. 中断可重入；`--rollback` 恢复备份并校验前后一致。
7. 用临时 `DSH_HOME` + 临时 Bank 验证；不碰真实个人库。

## 完成标准
- 含旧 bundle 的临时 profile 迁移成功，其他条目不变。
- `--rollback` 恢复原状。
- 数据目录不被删除，迁移中断可重入。
- DA05、DA06、DA07 通过。
