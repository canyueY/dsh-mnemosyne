# D00｜建立 DSH 安装/迁移基线

## 目标
确认当前根适配层在 DSH 0.2.1 下可复现，记录版本与现有缺口，作为后续任务的基线。

## 步骤
1. 运行 `node -v`、`npm -v`、`dsh --version`（若可解析），记录 Node/DSH 版本。
2. 运行 `npm test` 与 `npm run check`，确认 7 项 host 测试全绿。
3. 只读核对 `package.json`（`engines.dsh`、`dsh.manifestVersion`、`dsh.bundle.patch`）、`dsh.plugin.json`（`entry.inject`）、`cordis.patch.yml`。
4. 用临时 `DSH_HOME` + 临时 profile 实测 `dsh plugin --profile web add "file:<仓库绝对路径>"` 能自动追加 bundle。
5. 写 `reports/D00.md`：版本、命令输出、发现缺口；更新 `PROGRESS.json` 把 D00 标记 done。

## 完成标准
- `npm test` / `npm run check` 全绿。
- 临时安装实验 bundle 追加成功，profile 其他条目未丢失。
- DA01 通过。
