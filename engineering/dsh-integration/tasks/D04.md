新增 `dsh/agent-presets/mnemosyne`，为 DSH Agent 提供 memory 工具使用说明与白名单，作为 `defineTool` 之外的显式入口。

## 步骤
1. 新增 `dsh/agent-presets/mnemosyne/agent.cordis.yml`：

2. 通过 bundle patch 把 preset 注册为 `@deepseek-ai/dsh-agent-preset` 行。
3. 验证 `agentPresets/list` 含 `mnemosyne`，`session/create` 可用该 preset。
4. 新增 `src/test/preset.test.mjs`：preset 形状、白名单 fail-closed、preset 可被 session/create 接受。
