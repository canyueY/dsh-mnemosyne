# D03｜DSH 设置页 namespace

## 目标
把 `dsh-mnemosyne` 配置暴露为 DSH 设置 namespace，替代纯 `ctx.get('config')` 手填。

## 步骤
1. 确认 DSH 0.2.1 settings namespace 派生方式（entry id + Config）；不依赖已删除的 `ctx.settings.register`。
2. 新增 Config schema：`auto_start`(bool, 默认 true)、`service_root`(string)、`data_dir`(string)、`python`(string)、`base_url`(string)、`token`(string, secret)、`auto_capture`(bool, 默认 true)。
3. `dsh.plugin.json` 或 `cordis.patch.yml` 增加 settings 注入（按当前宿主机制，记录等价实现）。
4. `apply(ctx)` 同时读 settings 与旧 `ctx.get('config')`，后者只作兼容回退，不形成两套真相。
5. secret 字段只写不读回，脱敏 `********`，不进日志；非法值拒绝。
6. 新增 `src/test/settings.test.mjs`：`settings.describe` 列出 namespace、`settings.update` 持久化、secret 脱敏、非法值拒绝。

## 完成标准
- settings namespace 可见可写；配置改动实际作用于 `apply`。
- secret 不读回、不落日志。
- DA08、DA09、DA10 通过。
