# D05｜MCP 接口

## 目标
把核心 memory 能力通过 MCP stdio gateway 暴露（`mcp__mnemosyne__*` 或等价命名），不依赖 `defineTool` 单一入口。

## 步骤
1. 复用/新增 `service/src/cognitive_memory/mcp/` 的 MCP gateway：`initialize` / `ping` / `tools/list` / `tools/call`（MCP 2025-06-18）。
2. 暴露 `memory_search/get/context/observe/propose/feedback/update/forget/task_status/health`，走 Node REST，不直连 SQLite。
3. 错误结构化：非法参数 `-32602`、未知工具 `-32601`、未初始化 `-32600`；不泄漏内部表名/路径/密钥。
4. 新增 `src/test/mcp.test.mjs`：tools/list 含 memory 工具、tools/call 合法与非法路径、未初始化报错。

## 完成标准
- `tools/list` 返回 memory 工具；`tools/call` 合法调用返回结构；非法调用结构化失败。
- MCP 网关不直连 SQLite。
- DA13、DA14、DA15 通过。
