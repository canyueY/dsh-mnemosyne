# M01｜检索候选与认识裁决分离

## 目标
把“检索命中”和“认识结论”拆成两层，排序命中不得写 verified。

## 步骤
1. 明确 retrieve/rank 只返回 `candidate + sort_score + retrieval_reason`。
2. 明确 select/decide 输出 `decision_id + status(chosen|partial|unknown) + evidence_refs + counterevidence_refs + checks_complete + budget_usage + reason_codes + trace_id`。
3. `chosen` 表示有限结论，不写数据库 verified；verified 仍由 VerificationEngine 产生。
4. 新增大额返回结构到 Service/API/SDK；旧 search/retrieve 语义兼容。
5. 回归与新增测试：候选排序命中不晋升、证据不足 unknown、反证待审 partial。

## 完成标准
- select 状态机真实接入 API/SDK。
- MA02、MA03、MA04 通过。
