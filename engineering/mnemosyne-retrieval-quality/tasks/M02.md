# M02｜证据独立性与时间适用性

## 目标
证据计数不冒充独立支持；时间降权不冒充时间适用性。

## 步骤
1. 证据组合用支持/反对 justification graph，独立支持根按 `root_source_id + revision + content_hash` 去重。
2. 时间用 `validity [from, to)` + 状态机；查询时刻求区间交集，输出 `applicable_now / applicable_at(t) / not_yet / expired / superseded / unknown`。
3. `recency` 只作排序先验，不进事实概率。
4. 接入 Evidence/Claim/Verification 主链路；新增时间适用性测试（过期、未生效、被替代、撤回后独立支持保留）。

## 完成标准
- 独立支持根可审计，换 producer/导入格式不改变根。
- 时间适用性裁决真实生效。
- MA05、MA06、MA07 通过。
