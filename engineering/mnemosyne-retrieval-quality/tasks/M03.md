# M03｜多路召回、RRF 融合与反证保护

## 目标
确定性轨道完成 BM25/FTS + lexical + 规则反证召回，用 Reciprocal Rank Fusion 融合；dense embedding/cross-encoder 标 disabled 直到有真实模型。

## 步骤
1. 实现多路召回框架：`BM25/FTS`、`lexical`、`规则反证`（否定/对比 query）。
2. 实现 RRF：`score = Σ 1/(k + rank_i)`，`fusion_method=rrf`，记录 `sources[]` 与各路 rank。
3. 支持证据与 `counterevidence_refs` 同进 select，不被正分淹没。
4. 本地哈希只输出 `candidate_similarity`；无 embedder 时 `semantic_model=unavailable`。
5. 新增融合/反证测试；不宣传语义理解。

## 完成标准
- RRF 多路融合真实生效；反证召回进入 select。
- 无 embedder 时明确 unavailable，不冒充语义质量。
- MA08、MA09、MA10 通过。
