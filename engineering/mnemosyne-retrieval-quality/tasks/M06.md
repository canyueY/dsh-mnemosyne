# M06｜统一账本、消费水位与会话恢复

## 目标
把 Trace.cost 升级为 host/Node 共用 UsageLedger；把 checkpoint 升级为带 fencing 的会话恢复。

## 步骤
1. UsageLedger 键 `correlation_id + attempt + provider + meter_scope(host/node/embedding/retry)`；`reserved` 与 `actual` 分开；`unknown` 不转零。
2. outbox + 幂等 key，至少一次投递 + 幂等消费；业务效果与 `consumer_watermark` 同事务。
3. checkpoint 携带 `fencing_token / 代次 / expected_version`，写前校验。
4. 恢复时重新核对来源新鲜度，未知副作用先核对不盲重试。
5. 新增账本/水位/fencing/恢复测试。

## 完成标准
- 账本按 meter_scope 去重；水位与业务效果同事务。
- fencing 拒绝过期写；恢复不盲重试。
- MA16、MA17、MA18 通过。
