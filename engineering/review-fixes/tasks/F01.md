# F01｜R01：Checkpoint 跨 Bank 覆盖授权

## 目标
阻止持某 Bank 写权限的 Agent 通过已知 checkpoint_id 篡改其他 Bank 任务状态。

## 步骤
1. 在 `session_checkpoint.py` 更新前于同一事务读取既有记录的 `bank_id`、`session_id`、`version`。
2. 新 body 的 `bank_id` 与既有记录不一致或会话不同时返回拒绝，不执行 UPSERT。
3. SQL 更新条件绑定已授权范围；跨 Bank 冲突返回结构化错误。
4. 补两个 REST 反例：personal 权限试图覆盖 projects 记录被拒；同 Bank 正常更新成功。

## 完成标准
- FA02（cross_bank_checkpoint_overwrite）转为拒绝。
