# F05｜R05：补齐 npm 发布包文件

## 目标
npm 打包产物包含安装/迁移脚本与 preset 资源，干净目录可用。

## 步骤
1. 更新 `package.json` 的 `files` 白名单：`scripts/install-dsh.mjs`、`scripts/migrate-dsh.mjs`、`dsh/agent-presets/**` 及必要文档。
2. 重新 `npm pack --dry-run --json --ignore-scripts`，确认关键文件在列。
3. 在解包干净目录验证 `install-dsh.mjs --help`、`migrate-dsh.mjs --help` 与 preset 资源加载。

## 完成标准
- FA09（pack 含关键文件）；FA10（打包产物干净目录可执行）。
